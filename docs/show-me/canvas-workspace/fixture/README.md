# Lantern Walks

Fictional project for the canvas design fixture. It shows the proposed canvas
files; see [the design](../../../product/canvas-workspace.md).

This folder has one record on purpose. The viewer lists a folder as a project
only when it has two or more core records, so this fixture does not show as a
project.

## What it is

Guided evening walks through the old harbour, with stories at each stop.

## Get started

Open the booking page, pick a date, and pay the deposit. The guide meets you
at the lighthouse steps.
